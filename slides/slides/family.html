2 · THE FAMILY

Three ways to train a small add-on

Adapters

Houlsby et al. 2019

Trains: small bottleneck layers inserted in every block

Inference: extra sequential layers add latency

Paper: within 0.4 % of full fine-tuning on GLUE, with 3.6 % extra parameters per task

LoRA

Hu et al. 2021

Trains: a parallel low-rank path B·A beside each frozen matrix

Inference: merged into W₀, zero added latency

Paper: GPT-3 175B with 10,000× fewer trainable parameters and 3× less GPU memory

QLoRA

Dettmers et al. 2023

Trains: LoRA on a frozen base stored in 4-bit NF4

Inference: 4-bit weights de-quantized on the fly

Paper: fine-tunes a 65 B model on a single 48 GB GPU

Houlsby et al., ICML 2019 · Hu et al., ICLR 2022 · Dettmers et al., NeurIPS 2023

Speaker B · 1:35–2:00. One sentence per card. Adapters came first: extra small layers inside each block, which add latency because they run in sequence. LoRA puts the small part in parallel, so it can be merged away after training. QLoRA keeps LoRA but stores the frozen base model in 4 bits (NF4), plus double quantization and paged optimizers, which is how a 65 B model fits on one 48 GB GPU. Colour key for the rest of the talk: orange = LoRA, green = QLoRA, blue = full fine-tuning.
